# InsightBoard

This is a Next.js application called InsightBoard, generated by Firebase Studio. It provides an interactive dashboard for analyzing data from a CSV or JSON file.

## Features

- **Dynamic Data Loading**: Upload your own CSV or JSON data.
- **Multiple Analysis Views**: Switch between different perspectives on your data using tabs.
- **Interactive Visualizations**: Includes KPI cards, filterable tables, and interactive charts.
- **AI-Powered Insights**: Generate insights on your data using AI.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.

## Data Format

The application expects data with a structure similar to the initial sample data found in `src/lib/data.ts`. Key columns used for analysis include:

- `Дата` (Date)
- `Тип события` (Event Type: 'предложение', 'спрос', 'приглашение')
- `Роль` (Role)
- `Компания` (Company)
- `Ниша / уникальная экспертиза` (Niche)
- `Гео / локация` (Location)
- `Ставка (руб/ч)` (Rate)
- `Связь (from → to)` (Connection)

You can upload your own data using the "Upload Data" button in the application.

## Tech Stack

- **Framework**: Next.js
- **UI**: React, Tailwind CSS, ShadCN UI
- **Charting**: Recharts
- **AI**: Google Genkit
- **CSV/JSON Parsing**: Papa Parse
