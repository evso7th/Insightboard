# **App Name**: InsightBoard

## Core Features:

- Data Loading: Loads data from a CSV or JSON file, or from a local API, and parses the data for analysis.
- View Selector: Provides an interactive view selector (tabs) to switch between different data analysis perspectives.
- KPI Indicators: Displays key performance indicators (KPIs) relevant to the selected analysis view.
- Data Tables: Presents filterable and sortable tables summarizing the data for each analysis view.
- Interactive Charts: Generates interactive charts (line, bar, pie, heat map, network graph, and box plot) to visualize data trends and relationships, based on the selected analysis view.
- AI Insights: AI-powered insights generation tool which analyzes the data to highlight significant trends, anomalies, and correlations, and presents these as key insights for each view.
- Data Source Flexibility: Enables users to easily switch the source data file without needing to recompile or redeploy the application, and to reflect those changes in the visualization. CSV/JSON formats.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to convey professionalism and analytical depth.
- Background color: Very light grey (#F5F5F5), almost white, for a clean, uncluttered backdrop.
- Accent color: Cyan (#00BCD4) to highlight interactive elements and key data points, providing contrast and focus.
- Body and headline font: 'Inter', a sans-serif font providing a modern and neutral feel for both headlines and body text.
- Simple, clean icons from a set like Material Design Icons to represent different data categories and actions.
- A clean, grid-based layout to ensure data is presented in an organized and easily digestible manner. Use of white space to avoid clutter.
- Subtle transitions and animations on data updates and user interactions to provide visual feedback and enhance the user experience without being distracting.
